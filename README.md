# Прогноз схвалення займу

Веб-застосунок на Django, який за даними заявки прогнозує, чи буде схвалено займ.
Прогноз робить модель машинного навчання, натренована на наборі даних `loan_data.csv`.

Фінальний проєкт курсу Python у DAN.IT Education.

## Можливості

- **Форма заявки.** Усі поля обов'язкові. Значення доходів і суми займу обмежені діапазоном,
  який є в навчальних даних: за його межами модель прогнозувати не може.
- **Результат.** Рішення "схвалено / відмова" та ймовірність схвалення.
- **Історія заявок.** Усі заявки з введеними даними й рішенням зберігаються в базі SQLite.
- **Про модель.** Якість на тестовій вибірці, порівняння моделей, матриця помилок
  і важливість ознак.

## Технології

- Python 3.14
- pandas, NumPy - обробка даних
- scikit-learn - Pipeline, GridSearchCV, RandomForestClassifier
- Matplotlib, Seaborn - графіки
- Jupyter Notebook - аналіз даних
- Django 6.1, SQLite - веб-застосунок

## Дані

381 заявка, 11 ознак і цільова колонка `Loan_Status` (Y - схвалено, N - відмова).
Схвалено 71% заявок, відхилено 29%.

| Колонка | Зміст |
|---|---|
| Gender, Married, Dependents, Education, Self_Employed | стать, шлюб, кількість утриманців, освіта, самозайнятість |
| ApplicantIncome, CoapplicantIncome | дохід заявника і співзаявника |
| LoanAmount | сума займу в тисячах |
| Loan_Amount_Term | строк займу в місяцях |
| Credit_History | кредитна історія відповідає вимогам (1) чи ні (0) |
| Property_Area | район нерухомості: місто, передмістя, село |

Пропуски є в п'яти колонках (найбільше в `Credit_History` - 7.9%). Рядки з пропусками
не видаляються: пропуски заповнюються всередині Pipeline.

## Модель

- **Обробка даних у Pipeline:** числові ознаки - медіана замість пропусків і StandardScaler,
  категоріальні - найчастіше значення і OneHotEncoder.
- **Вибір моделі:** GridSearchCV з 5-кратною перехресною валідацією порівнює
  RandomForestClassifier і LogisticRegression за метрикою F1 macro.
  Accuracy не підходить: модель, яка завжди відповідає "схвалити", вже має 71%.
- **Розбиття:** 80% на навчання, 20% на тест, зі збереженням співвідношення класів.

| | F1 macro |
|---|---|
| RandomForest з параметрами за замовчуванням (перехресна валідація) | 0.758 |
| RandomForest після GridSearchCV (перехресна валідація) | 0.766 |
| LogisticRegression після GridSearchCV (перехресна валідація) | 0.763 |
| Обрана модель на тестовій вибірці | 0.788 |
| Модель "завжди схвалити" на тестовій вибірці | 0.417 |

Точність на тестовій вибірці - 86%. Модель розпізнає всі схвалені заявки і половину відмов.

## Обмеження

Головна ознака - кредитна історія: з доброю історією в даних схвалено 82% заявок,
без неї - 5%. Доходи, кількість утриманців і сума займу майже не впливали на рішення
банку в цих даних, тому модель їх майже не враховує.

`Loan_Status` - це рішення банку про схвалення, а не факт повернення боргу.
Модель прогнозує, чи схвалив би цей банк заявку, а не чи здатна людина повернути займ.
Для оцінки платоспроможності потрібні дані, яких у наборі немає: витрати, інші борги,
історія погашень.

## Встановлення і запуск

Потрібні Python 3.14 і Git.

1. Клонувати репозиторій:
   ```
   git clone https://github.com/patseluk-lang/loan-approval-prediction.git
   cd loan-approval-prediction
   ```
2. Створити й активувати віртуальне оточення.

   Windows:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   ```
   macOS:
   ```
   python3 -m venv .venv
   source .venv/bin/activate
   ```
   Linux:
   ```
   python3 -m venv .venv
   source .venv/bin/activate
   ```
   В Ubuntu і Debian модуль `venv` встановлюється окремо: якщо перша команда
   повідомить, що `ensurepip` недоступний, виконайте `sudo apt install python3-venv`.
   Після активації команда `python` в оточенні працює однаково на всіх системах.
3. Встановити залежності:
   ```
   pip install -r requirements.txt
   ```
4. Створити базу даних:
   ```
   python manage.py migrate
   ```
5. Запустити сервер:
   ```
   python manage.py runserver
   ```
   і відкрити в браузері http://127.0.0.1:8000/

Навчена модель уже лежить у `ml/`. Щоб навчити її заново:
```
python train_model.py
```

Аналіз даних відкривається командою:
```
jupyter notebook analysis.ipynb
```

## Тести

```
python manage.py test loans
```
